TENTANG PROYEK

Mengenal Urbanicity

Sebuah platform peta web interaktif untuk mempermudah siapa saja mempelajari letak geografis dan data administratif provinsi di Indonesia.

Urbanicity berawal dari proyek belajar siswa di IDN Boarding School Solo. Tujuan kami membuat web ini sangat sederhana: menghadirkan peta digital Indonesia yang tampilannya bersih, nyaman dilihat dengan mode gelap, serta ringan saat dibuka di perangkat apa pun.

Dengan memanfaatkan pustaka Leaflet.js dan data terbuka dari EMSIFA Indonesian Regional API, website ini memuat 38 provinsi di Indonesia mulai dari Sabang di ujung barat Aceh hingga Merauke di ujung timur Papua. Pengguna bisa melihat titik koordinat, ibu kota daerah, estimasi populasi, serta luas wilayah secara langsung dan real-time.

Fokus Area Nusantara

Peta dibatasi khusus wilayah Indonesia agar penjelajahan tetap fokus dan tidak tergeser keluar dari kepulauan Nusantara.

Data Terbuka EMSIFA API

Terhubung langsung dengan API data wilayah Indonesia untuk menampilkan kode provinsi resmi, ibu kota, dan data demografi.

Pencarian & Panel Cepat

Daftar kartu di bawah peta memudahkan pencarian provinsi tertentu dan bisa langsung mengarahkan kamera peta ke titik lokasi.

Urbanicity dikembangkan sebagai sarana praktik pemrograman web dan pengolahan data geospasial oleh siswa di IDN Boarding School Solo. Proyek ini akan terus kami kembangkan agar semakin informatif.

TAMBAHAN

Tentang Leaflet dan EMSIFA

Pemberian terima kasih kepada EMSIFA dan Leaflet.

Leaflet.js adalah pustaka JavaScript open-source yang ringan dan andal untuk merender peta interaktif. Diciptakan pertama kali oleh Volodymyr Agafonkin dan kini dikembangkan secara kolektif oleh komunitas kontributor global. Tertarik ikut berkontribusi? Cek panduannya di GitHub Leaflet, atau dukung langsung pembuatnya melalui inisiatif Stand with Ukraine.

Website ini menggunakan API Wilayah Indonesia yang dikembangkan oleh Muhammad Syifa (EMSIFA) sebagai sumber data administratif regional yang gratis, cepat, dan siap pakai. Proyek sumber terbuka ini sangat membantu menyediakan data wilayah mulai dari tingkat provinsi, kabupaten/kota, hingga koordinat geografis tanpa perlu repot membangun backend sendiri. Dokumentasi dan repositori lengkapnya bisa kamu cek langsung di GitHub EMSIFA.
